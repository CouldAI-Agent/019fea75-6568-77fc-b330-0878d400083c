# SchoolRides

**Smart Tracking for Safe School Transport**

SchoolRides is a modern, professional, and fully responsive smart school transport tracking platform designed for schools, parents, drivers, and students. It helps parents track school buses, school vans, and school autos in real time with a clean, premium, and trustworthy blue-and-white design.

## Features
- **Live GPS Tracking**: Real-time vehicle location and estimated arrival times.
- **Multi-Vehicle Support**: Track school buses, vans, and autos.
- **Dedicated Dashboards**: Custom interfaces for Parents, Schools, and Drivers.
- **Student Safety & Security**: Arrival notifications and emergency alerts.
- **Cross-Platform Ready**: Works perfectly on Android, iOS, tablets, laptops, and desktop computers.

## Tech Stack
- Flutter (Web, iOS, Android, macOS, Windows, Linux)
- Responsive UI with `LayoutBuilder` and modern web design principles
- Google Fonts for premium typography

## Getting Started
To run the app locally:
```bash
flutter pub get
flutter run -d chrome
```
